## Dados de ponta a ponta: da coleta e modelagem ao dashboard que apoia a decisão

Sou analista de dados há três anos, em Uberlândia (MG). Trabalho em uma empresa de tecnologia de um grande grupo atacadista, onde atendo seis áreas de negócio: Financeiro, Comercial, Logística, Qualidade, PCP e Monitoramento Transacional. Faço a extração e a transformação dos dados e entrego os painéis e relatórios que cada área usa para decidir.

Gosto de transitar entre a análise e a engenharia de dados: entender a pergunta do negócio e também construir o caminho que leva o dado até a resposta.

### No dia a dia

- **Dados e código:** SQL, Python
- **Plataforma:** Databricks (SQL, notebooks em PySpark, tabelas Delta e jobs), AWS S3
- **Visualização:** Tableau, Power BI
